 Framingham Heart Disease Prediction using Machine Learning

 Project Overview
This project predicts whether a person is at risk of developing heart disease within the next 10 years using the Framingham Heart Study dataset. Multiple Machine Learning classification algorithms were trained, evaluated, and compared to identify the best-performing model.



 Objectives
- Predict the 10-year risk of heart disease.
- Perform Exploratory Data Analysis (EDA).
- Handle missing values and preprocess the dataset.
- Train multiple Machine Learning models.
- Compare model performance using evaluation metrics.

 Dataset
**Dataset:** Framingham Heart Study Dataset

**Target Variable:** `TenYearCHD`
